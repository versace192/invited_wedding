# Свадебное приглашение

Интерактивное приглашение Ильи и Екатерины на 19 сентября 2026 года.

## Запуск

```bash
npm run dev
```

Сервер запустится на `http://localhost:5173` или на следующем свободном порту.

## Визуальный фон

Фон первого экрана лежит в `assets/hero-bg.png`. Его можно пересобрать командой:

```bash
node scripts/generate-hero-asset.js
```

## Google Forms

Анкета уже умеет отправлять данные в Google Forms, но для этого нужны URL вашей формы и `entry.*` идентификаторы полей.

1. Создайте Google Form с полями: ФИО, присутствие, спутник/спутница, предпочтения.
2. Возьмите `formResponse` URL формы и `entry.*` имена полей из HTML опубликованной формы.
3. Заполните `config.js`.

Пока `config.js` не заполнен, ответы сохраняются в `localStorage` браузера.
